# 安全遮蔽 · PDF 個資遮蔽工具

線上版：**https://pdf-redactor-maker.web.app**

給同事用的 PDF 敏感資料遮蔽工具。所有處理都在瀏覽器本機完成，**檔案不會上傳到任何伺服器**。

## 功能

- **自動偵測**（本機規則引擎）：金額（含幣別、匯率、稅費）、手機、市話、身分證字號、Email、信用卡號、銀行帳號、出生日期、統一編號、地址、姓名、稅率、報單號碼、提單號碼
- **手動框選遮蔽**：支援滑鼠拖曳與手機觸控
- **浮水印**：直接印在導出檔上，非僅預覽
- **真遮蔽輸出**：整頁光柵化，PDF 內**不留任何文字層**，複製／搜尋都取不到原文

## 為什麼不用 AI / LLM 當引擎

1. 這類資料有**固定格式**，regex 的召回率與穩定度都優於 LLM，且不會幻想出不存在的內容。
2. 不呼叫外部 API＝PDF 不出瀏覽器。處理薪資、個資時這是最重要的屬性。
3. 零 API key、零費用、離線也能用（載入後）。

## 技術決策

- **輸出＝逐頁 render 成 JPEG 再組回 PDF**（pdf-lib）。只疊黑方塊的作法，PDF 裡原始文字仍在，隨手就能複製出來，不能算遮蔽。
- 輸出解析度 2x（A4 約 1190×1684），檔案大小約 1/3～1/2 原檔。
- 中文浮水印畫在 canvas 上，不需嵌入字型檔，無亂碼問題。

## 開發

```bash
npm install
npm run dev      # 本機開發
npm run build    # 產出 dist/
```

## 部署

Firebase Hosting（多站點，掛在 `travel-collection-34302` 專案下的 `pdf-redactor-maker` site）：

```bash
npm run build
firebase deploy --only hosting:redactor
```

## 報關文件支援

針對台灣進口報單（D2 等）特別處理：

- **金額**：離岸價格、起岸價格、完稅價格、運費、保險費、進口稅、營業稅、稅費合計、營業稅稅基、推廣貿易服務費
- **匯率**：`匯率(16)` 欄位數值
- **稅率**：`5%` 這類百分比
- **單價**：`CIF THB 256` 這種純整數單價（靠「單價」表頭垂直對齊推斷）
- **報單號碼 / 提單號碼**
- **排除**：淨重、毛重、數量、件數（`11,700.00KGM`、`1,500.00BOX` 不會被誤遮）

## 已知限制

- 掃描件（圖片型 PDF）沒有文字層，自動偵測抓不到，需手動框選。
- 姓名沒有規則可抓（無固定格式），需手動框選。
- 導出時間約每頁 5–10 秒（依裝置與頁面複雜度）。
- 頁數多的大檔在手機上可能吃記憶體，建議電腦處理大檔。
